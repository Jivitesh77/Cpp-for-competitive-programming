# 🏆 Ultimate C++ Competitive Programming Template

Welcome to my all-in-one C++ toolkit for competitive programming! This repository contains a master C++ file packed with everything needed to tackle algorithmic challenges efficiently on platforms like Codeforces, CodeChef, LeetCode, and AtCoder.

Whether you are looking for a fast, reliable boilerplate or a quick reference for the C++ Standard Template Library (STL), this file has you covered.

## ⚡ Features

*   **Fast I/O Setup:** Eliminates input/output bottlenecks with `std::ios_base::sync_with_stdio(false)` and `std::cin.tie(NULL)`, ensuring your code executes well within strict time limits.
*   **Time-Saving Macros:** Heavily utilized `typedef`s (e.g., `ll` for `long long`) and macros (`FOR`, `all()`, `pb`, `sz`) to drastically reduce typing time during timed contests.
*   **Complete STL Arsenal:** Ready-to-use syntax and configurations for the most crucial C++ data structures:
    *   `std::vector` (Dynamic Arrays)
    *   `std::set` / `std::multiset` (Balanced BSTs)
    *   `std::map` / `std::unordered_map` (Hash Tables & Dictionaries)
    *   `std::priority_queue` (Min/Max Heaps)
    *   `std::deque` / `std::queue` / `std::stack`
*   **Algorithmic Utilities:** Pre-written utility functions for common CP hurdles, such as custom sorting comparators, GCD/LCM, and modular arithmetic.

## 🚀 How to Use

1. Clone or download the repository.
2. Copy the contents of the master `.cpp` file into your local IDE or code editor.
3. Write your contest logic inside the `solve()` function (or `main()`).
4. Compile and run! 

## 🛠️ Requirements

*   Any standard C++ compiler (GCC, Clang, MSVC) supporting **C++14** or higher (C++17/C++20 recommended).
